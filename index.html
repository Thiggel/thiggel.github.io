ICLR 2026 · Main conference · Poster

What layers when: Learning to skip compute in LLMs with residual gates

F. Laitenberger, D. Kopiczko, C. G. M. Snoek, Y. M. Asano

GateSkip puts a small gate on every residual branch of a language model. Tokens with the lowest gate values skip that layer, so the model learns for itself where it can save compute.
